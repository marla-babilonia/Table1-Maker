How to use Table 1 Maker

Keep this page open while you work in the Table 1 Maker tab.

1. Choose your data

Select a comma-separated CSV or an Excel workbook ending in .xlsx. Use unique column names in the first row and one record per row below. If the workbook has multiple sheets, choose the worksheet to analyze.

The app reads the selected file in your browser. Your edits apply to the table you create. The original file stays as saved.

2. Identify IDs and choose variables

Mark columns such as record ID as identifiers, then select the columns to summarize. Review whether each included column should be numerical or categorical. Marking an ID excludes that column from summaries. Counts are based on rows.

To create a combined categorical column, open Merge two columns. Choose two sources and keep all values or selected values from each. The app combines retained values within each record.

3. Review numerical and categorical variables

  • For numerical variables, choose mean (sample SD) or median [Q1, Q3]. You can add individual statistics as indented rows.
  • Choose the number format for values such as 1,25 or 1,250. A red correction box needs review. Apply a valid correction or mark it missing to turn it green.
  • For categorical variables, choose which categories to show. Keep a cell such as Boston, MA together, or split a cell such as 1,4 if it represents two responses.
  • Use Merge values in this column to combine selected categories into a named category. If a record contains both selected values, it counts once in the merged category.

4. Stratify the table, if needed

Choose a grouping variable, such as diagnosis, to add one column per selected group. For a numerical variable, enter cut points separated by semicolons. For example, 40; 65 creates under 40, 40 to under 65, and 65 or higher.

Choose which strata to display and edit their column names. The cohort column can include every record or only records in the displayed strata. If strata overlap, a record counts once in the combined cohort.

5. Edit names, preview, and download

Set the table title and column names. Click Edit next to a category to rename it or insert a heading before it. Choose whether to show record counts, missing counts, bold headings, an editable footer, or a complete statistics sheet in Excel.

Generate the preview. Use Reorder rows to move headings and categories. When the table is ready, download Excel or PDF. Both exports use the order shown in the preview.
